# Проверка PDF Telegis

Слайды исправлены для сборки на основе GitHub `97e7342`. Сохранены исходная композиция карточек, типографическая иерархия, экранная тема и светлые печатные стили. Убраны заявления о гарантированном прибытии, автоматическом GPS, неподтверждённых крытых хабах, безошибочности модели и заранее назначенные баллы.

## Фактический результат

- `presentation/slides.html` содержит 6 слайдов.
- `presentation/slides.pdf` содержит ровно 6 страниц A4 в альбомной ориентации.
- Все страницы экспортированы в изображения и визуально просмотрены после финального рендера: заголовки, текст, карточки, числа и последний блок помещаются; лишней страницы с одним подвалом нет.
- Извлечённый текст содержит соответственно 97, 140, 117, 127, 117 и 112 слов на страницах. Это дополнительная проверка; она не заменяла визуальный просмотр.
- Ошибка `CHROME_PATH` проверена отдельно: экспорт завершился кодом 1, SHA-256 прежнего PDF остался тем же.

Эта проверка относится к PDF и его текстам. Она не подтверждает работу интерфейса, доступность внешней модели или загрузку видео. Их результаты фиксируются отдельно в [final-evidence.json](../docs/final-evidence.json).

## Воспроизведение

```powershell
node scripts/generate_slides_pdf.js
```

Скрипт использует только стандартную библиотеку Node.js и установленный Chrome/Chromium/Edge. Он открывает собственную локальную копию HTML без внешних ссылок на шрифты и без JavaScript, с отдельным временным профилем. Стили печати определяют размер и переносы. Сервер Telegis запускать не требуется.

Переопределения: `CHROME_PATH` — путь к браузеру, `PDF_OUTPUT` — путь к PDF. В данном ограниченном Windows-окружении дочерние процессы встроенной песочницы Chrome не запускались. Поэтому для рендера собственного локального документа был явно использован:

```powershell
$env:PDF_CHROME_NO_SANDBOX='1'
node scripts/generate_slides_pdf.js
```

По умолчанию эта настройка выключена. Она относится только к временному процессу экспорта, не меняет браузер пользователя и не предназначена для открытия неизвестных сайтов или чужого HTML.

После изменения текста снова отрендерите и просмотрите **все** страницы: наличие шести HTML-секций само по себе не исключает переполнение печатного листа.
