# Telegis: готовность бэкенда 1.1

Проверено 19 октября 2026 года. Бэкенд, датасет и реальный OpenRouter готовы для интеграции двух основных сценариев: прогулка и кофе. Интерфейс, презентация и YouTube-видео не входят в эту проверку.

## Подтверждённые проверки

- **98 автоматических тестов прошли**: контракт, релевантность, ограничения, приватность, ошибки провайдера, целостность данных, атомарное обновление, интеграция static-файлов.
- **10 из 10** сценариев на реальном сохранённом датасете: [verification.json](verification.json), [test-scenarios.md](test-scenarios.md).
- Реальный HTTP → бэкенд → OpenRouter → валидация: прогулка **rag, 4,75 с**, кофе **rag, 2,67 с**. Отчёты: [live-rag-walk.json](live-rag-walk.json), [live-rag-cafe.json](live-rag-cafe.json). Это замеры конкретных запросов, не гарантированная задержка.
- Локальная диагностика `scripts/doctor.py` подтверждает валидность конфигурации/датасета; `scripts/start.ps1` корректно распознал занятый порт без остановки чужого процесса.

## Данные и автоматизация

49 реальных именованных POI, исходный ответ — 156 объектов. Время получения `2026-10-19T17:00:13+00:00`; снимок `20261019T170214Z-5f17a02a`. SHA-256 raw: `182a541719a8a5f7136918688b8d8857e7330a99689f0af3bdc02e0ddfdb6de6`.

Сборщик Overpass сохраняет исходный ответ, нормализует и удаляет дубликаты, проверяет снимок до переключения указателя. Загрузка API проверяет checksum, источники, координаты стартовых точек, категории и счётчики. Ошибка нового сбора/публикации сохраняет предыдущий рабочий снимок.

Часы есть у 15 POI, контакты — у 14, подтверждённый Wi-Fi — у 5. API возвращает контакты, описание, источник и явную пометку идеи занятия. Полнота доступна в `/api/meta.data_quality`.

## Исправления относительно первой передачи

- Название в API, Swagger, метаданных и документации — **Telegis**.
- Устранён HTTP 402 OpenRouter из-за отсутствующего ограничения ответа: теперь максимум 1200 токенов, reasoning отключён для выбранной модели.
- Различаются сбои ключа, средств, частоты, сети, таймаута и формата без раскрытия ответа провайдера или ключей.
- Исправлены ошибочные трактовки «в одиночку», временного бюджета, отрицания категорий, ориентира возле музея, запроса с ребёнком и отменённых требований.
- Явные численные лимиты сужают выдачу и отражаются в `used_context`. Ранг релевантности сохраняется после LLM.
- Телефоны/сайты из датасета доходят до API; небезопасные URL не публикуются в поле сайта.

## Запуск и повторная проверка

В `.env` выбран `https://openrouter.ai/api/v1`, модель `openai/gpt-5.6-terra`, `LLM_REASONING_EFFORT=none`, `LLM_MAX_TOKENS=1200`. Ключ хранится только локально; в Git и архив он не включается.

После изменения `.env` перезапустите сервер. Проверка работающего сервера: `python scripts/check_live.py --require-rag`; кофе: добавьте `--category cafe`. Эти команды вызывают платный API. `python scripts/doctor.py` работает без платного вызова; `--live` проверяет модель непосредственно.

## Честные границы

Район EXPO/Mega, до 2,5 км по прямой от пользователя. Время приблизительное, режим работы сейчас не подтверждается. Нет подтверждений розеток, тишины и wheelchair; рейтинги, мероприятия, цены и интерактивность не выдумываются. Полноценная маршрутизация и произвольное понимание языка не реализованы.
