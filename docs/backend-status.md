## Оставшийся шаг для проверки настоящего RAG

Выбран прямой OpenAI API: `LLM_BASE_URL=https://api.openai.com/v1`, `LLM_MODEL=gpt-5.6-terra`, `LLM_REASONING_EFFORT=none`.

1. Добавить свой ключ в `LLM_API_KEY` локального `.env`. Этот файл исключён из Git; ключ не передавать в чат или интерфейс.
2. Перезапустить сервер по инструкции README, чтобы он перечитал настройки.
3. Выполнить `python scripts/check_live.py --require-rag`. Успех этого шага подтверждает настоящий вызов модели; простой успех в `fallback` его не заменяет. Вызов может тарифицироваться провайдером.

Для OpenRouter или другого совместимого провайдера укажите его base URL и доступный идентификатор модели; если параметр reasoning_effort не поддерживается, оставьте `LLM_REASONING_EFFORT` пустым. Совместимость проверяется той же командой.
