# Telegis: соответствие критериям

Проверка текущего исправления GitHub `97e7342`. Баллы назначает жюри; автоматические проверки не заменяют пользовательское исследование. Подробное соответствие «реализация → проверка → ограничение»: [матрица доказательств](evidence-matrix.md). Результаты фактического прогона: [final-evidence.json](final-evidence.json).

| Критерий | Реализация | Ограничение |
|---|---|---|
| Релевантность и полезность | Реальные POI, BM25 по описаниям и фактам, подтверждённые свойства, сценарии семьи, туриста и вечернего осмотра. | Район EXPO / Mega Silk Way; понимание запроса основано на ограниченных правилах. |
| Контекст и адаптация | Расстояние, бюджет, возврат, резерв, локальный граф. Модельная погода с источником и временем. | Скорость, доступность проходов и время работы сегодня не проверены. Климатическое условие может обоснованно остановить поиск. |
| Объяснения | `why`, `activity`, факты, источники, даты и предупреждения; 75 фактов для 35 POI. | Идея занятия не означает существующее событие. Исторические источники остаются историческими. |
| UX и демо | Карта, карточки, мини-маршрут, отдельный путь к точке, состояния ошибок и неизвестности, GPS по клику. | Результаты браузерного прохода относятся к конкретному окружению. Тайлы и шрифты зависят от внешних сервисов. |
| Креативность | Круговой маршрут через 2–3 места с проверкой бюджета и возвращения; погодное условие не подменяет неизвестные свойства места. | Нет гарантии крытого или безопасного пути, группового планирования и актуальных событий. |
| Этика и приватность | Источники отделены от идей; ключ на сервере; сырой запрос и GPS исключены из контекста LLM. [Схема потоков](privacy-dataflow.md). | Сервер получает координаты для расчёта; провайдеры внешних ресурсов видят сетевые запросы. |
| Завершённость | Автоматизированный сбор, данные с манифестами, 356 тестов, инструкции, слайды HTML/PDF, видеодемонстрация: https://youtu.be/ZLQ37BQ5e6I | Полевые исследования запланированы на следующем этапе расширения на весь город. |

## Данные

134 POI: 49 именованных объектов и 85 площадок с явно описательными, неофициальными названиями. Обогащение: 75 фактов для 35 POI, включая 9 фактов из четырёх официальных страниц. Пешеходный граф: 30 829 узлов, 73 816 направленных связей.

Сбор воспроизводим: `python scripts/collect_pois.py --reprocess-current` перерабатывает сохранённый ответ OSM, сохраняя дату его получения. Это не новая загрузка. `python scripts/refresh_data.py` обновляет источники; при сбое соответствующий рабочий снимок сохраняется.

Рейтинг, розетки, тишина, возрастная пригодность оборудования и безбарьерность всего маршрута не выдумываются. Часы `24/7` — свидетельство источника, а не наблюдение текущей работы. Погода Open-Meteo — модельные значения для фиксированной точки EXPO, не измерение рядом с пользователем.

## Короткая демонстрация

1. Mega Silk Way, прогулка 60 минут: конкретные места, время с возвращением, причина и источник.
2. Мини-маршрут с кофе на 120 минут: последовательность, геометрия, возврат, сумма времени. При 60 минутах — отказ или иной подходящий план согласно текущим данным.
3. Погодный блок: источник, время модели и получения, явный статус. Климатическое условие при неизвестной погоде сохраняет ограничение и объясняет отказ.
4. «Кофе с розеткой»: без подтверждённых данных ответ не должен обещать розетку.
5. Путь к одной точке отличается от кругового мини-маршрута: он учитывает только дорогу туда.

Названия и числа берите из реального ответа текущего сервера. Исторические отчёты в этой папке сохраняют прежние результаты и не являются подтверждением новой сборки.
