## Продукт и приоритет

Telegis — AI-гид по Астане: помогает выбрать реальное место рядом под доступное время. Проверенное покрытие — район EXPO / Mega Silk Way.

Два сценария: прогулка и кофе. В текущем снимке 49 реальных POI, но фактическое число, дату и атрибуцию загружай из `/api/meta`, не зашивай в интерфейс.

Главная новая функция версии 1.2 — мини-маршрут с возвращением и запасом времени. Бэкенд уже реализован: `POST /api/itinerary`. После подключения обычных карточек добавь кнопку «Собрать мини-маршрут», переключатель «С кофе» и выбор 60/90/120 минут. Точный контракт, пример JavaScript и особенности геометрии — в `docs/itinerary-handoff.md`. Не пиши собственный расчёт маршрута в браузере. Проверенное демо: от Mega на 120 минут — 3 остановки, возвращение, расчётные 107 минут включая 12 минут запаса; при 60 минутах честный отказ с предложением бюджета.

Главная демонстрация: пользователь выбирает стартовую точку, прогулку и 60 минут, получает места, затем меняет бюджет на 20 минут — система пересчитывает выдачу. Если ничего не подходит, понятно объясняет почему. Не обещай, что при любом бюджете обязательно найдётся место.

## Запуск и соединение

Стек интерфейса — HTML/CSS/JavaScript без обязательной сборки. FastAPI отдаёт `/` из `static/index.html`, ресурсы из `/static/`. Все запросы относительные: `fetch('/api/...')`.

Запуск из корня по README:

```text
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --no-access-log
```

Если сервер уже работает на этом компьютере, используй его: http://127.0.0.1:8000 . Не запускай второй процесс на занятом порту и не останавливай чужой процесс. Документация доступна на `/docs`. На другом компьютере localhost означает тот компьютер, поэтому там нужен свой запуск сервера.

Папки `static/` пока может не быть. Её появление подхватывается без перезапуска сервера. Ресурсы в HTML указывай как `/static/styles.css` и `/static/app.js`.

## Контракт API

- `GET /api/locations` → `{"locations":[{"id":"...","name":"...","lat":0,"lon":0}]}`. Это схема типов; реальные координаты бери только из ответа.
- `GET /api/meta` → число/категории POI, происхождение и дата данных, покрытие, ограничения и атрибуция.
- `GET /api/health` → готовность датасета и наличие настроек модели. `llm_configured` НЕ подтверждает успешный вызов модели.
- `POST /api/recommend`: `{"query":"Хочу погулять","lat":51.0890897,"lon":71.4073303,"available_minutes":60,"category":"walk"}`. Используй выбранные пользователем координаты, а не фиксированный пример.

Категория — `walk` или `cafe`. Время — целое 10–180. Предложи кнопки 20/30/60 минут. Ответ содержит `mode`, `used_context`, `recommendations`, `message`.

В каждой карточке: `poi_id`, `name`, `lat`, `lon`, `category`, `distance_m`, `distance_kind`, `walk_minutes_estimate`, `visit_minutes_estimate`, `total_minutes_estimate`, `why`, `activity`, `opening_hours`, `source_url`, `collected_at`, `warnings`.

В версии 1.1 добавлены `description`, `phone`, `website`, `fact_source="OpenStreetMap"`, `activity_source="suggested_idea"`. Контакты могут быть null. Покажи имеющиеся контакты для уточнения расписания; телефон — текстом, сайт — безопасной HTTP/HTTPS-ссылкой. Не выдавай их за проверенную доступность.

`used_context` дополнен `effective_minutes`, `max_distance_m`, `required_features`, `excluded_categories`. Показывай фактическое время/расстояние и распознанные условия: текст «на 20 минут» может сузить выбранные в форме 60 минут. `/api/meta.data_quality` даёт полноту часов/контактов/подтверждённых свойств. Сохраняй совместимость с отсутствием новых необязательных полей.

Версия 1.2 добавляет `evidence[]` со ссылкой и датой каждого факта, `time_margin_minutes`, `travel_basis`, `route_distance_m`, `return_route_distance_m`, `route_connector_m`. `fact_source` также может быть `OpenStreetMap + official sources`. По-прежнему подпиши `distance_m` как «по прямой», а путь показывай отдельно, если он есть. Время при `travel_basis="osm_walking_graph"` рассчитано по графу OSM с приблизительными подходами. Дата старой статьи не означает подтверждения текущей доступности. NU Park намеренно исключён как неподтверждённый проект; не возвращай его моками.

`recommendations` — 0–3 элемента. Пустой массив с HTTP 200 — нормальная ситуация, покажи `message`. HTTP 422/503 — ошибка с `detail`, которое может быть строкой или массивом. Не показывай сырые объекты вместо понятного текста.

## Что сделать на экране

Сделай законченный, аккуратный адаптивный интерфейс на русском с названием Telegis и ясным объяснением пользы. Нужны выбор стартовой точки, необязательная кнопка «Моя локация», запрос, категория, бюджет времени и карточки.

В карточке покажи:

- название и категорию;
- расстояние с подписью «по прямой»;
- приблизительное время в одну сторону, посещение и общий бюджет;
- короткое «Почему подходит» из `why`;
- отдельный блок «Идея занятия» из `activity`;
- расписание либо «Часы не подтверждены»;
- предупреждения, источник и дату «Данные собраны».

Общий бюджет включает дорогу туда и обратно: `2 × walk_minutes_estimate + visit_minutes_estimate`. Это оценка, не гарантия. Карточки — независимые варианты, не остановки единого маршрута. Их время не суммируй.

Показывай использованную локацию, категорию и время. `mode="fallback"` означает ответ по данным и шаблонам: обозначай его явно. `mode="rag"` означает успешный проверенный ответ LLM. Не скрывай резервный режим ради красивого демо и не выводи «ИИ работает» по одному `llm_configured`.

Бэкенд теперь называется Telegis во всех метаданных. Два живых вызова OpenRouter уже проверены и записаны в `docs/live-rag-walk.json` и `docs/live-rag-cafe.json`; это результаты конкретного прогона, а не обещание доступности провайдера в будущем. Название приложения, заголовок вкладки и слайды используй **Telegis**.

Факты о местах и идея занятия должны отличаться визуально. Не добавляй вымышленные рейтинги, услуги, фото конкретных мест, состояние «открыто сейчас», события или неподтверждённые розетки.

## Надёжность

Обработай начальный экран, загрузку, результат, пустую выдачу, ошибку API и отказ в GPS. Геолокацию запрашивай только после нажатия; выбор точки из списка должен работать без неё. Не сохраняй GPS в localStorage или аналитике.

Отменяй устаревший запрос или игнорируй поздний ответ. После смены фильтров не представляй старый результат как новый. У кнопки загрузки должно быть понятное состояние, у ошибки — повтор.

Строки API выводи через `textContent`, а не небезопасный `innerHTML`. Для внешних ссылок допускай только HTTP/HTTPS. Добавь атрибуцию OpenStreetMap со ссылкой из `/api/meta`.

Тестовая фикстура допустима только при явном `?mock=1` и крупной подписи «Тестовые данные». По умолчанию — реальный API. Ошибки API не заменяй скрытыми моками. Финальное демо запиши без `?mock=1`.

Карта с реальными точками — только после рабочего полного сценария. Ключи для карты не требуются. Не выдавай прямую линию между объектами за пешеходный маршрут. Авторизация, личные кабинеты, новые источники и сложные анимации сейчас не нужны.

Для мини-маршрута используй готовые `route_coordinates` или `legs[].coordinates` в формате `[lon, lat]`. В Leaflet поменяй порядок координат. Отдельно покажи все остановки, обратный путь, итог и запас. Сохрани предупреждения о приблизительных подходах до 120 м с каждого конца и неизвестном текущем доступе. `status="network_unavailable"` не заменяй вымышленным маршрутом. Для `no_match` можно предложить кнопку с `suggested_minimum_minutes`, но менять бюджет только по явному нажатию пользователя.

## Проверка перед сдачей

В браузере проверь:

1. Прогулка от Mega Silk Way на 60 минут.
2. Смена бюджета на 20 минут, включая корректную пустую выдачу.
3. Кофе на 60 минут.
4. «Хочу тихое кафе с розеткой» — честное отсутствие подтверждений.
5. Недоступный сервер и повтор запроса.
6. Отказ в GPS.
7. Быстрое переключение фильтров без подмены результата запоздавшим ответом.
8. Узкий мобильный экран.
9. Отображение `fallback` и, если модель реально настроена, `rag`.
10. Мини-маршрут Mega на 120 минут: 3 остановки, обратный путь, сумма всех времён и запас.
11. Мини-маршрут Mega на 60 минут: объяснение и явное предложение другого бюджета.
12. Конкретные факты с источниками в карточке японского сада; предупреждение об историческом источнике.

Запиши фактические результаты в `presentation/frontend-checks.md`. Не помечай проверку успешной, если её не проводил.
